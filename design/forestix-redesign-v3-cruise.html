ForestiX v3 · 크루즈 모드

Tree Measurement(퀵 측정)는 현행 그대로 — 맵 홈·(+)·측정 시트·데이터 전부 불변. 재설계는 Cruise 원버튼 뒤의 크루즈 세계에만 적용: 지도-우선, 측정 우선, 정식 설계는 선택 사항.

화면

모드

⓪ 맵 홈 — 변경 없음 (경계 명시)
· Tree Measurement은 현행 유지 — 여기서 Cruise로 진입. 일부 사용자는 퀵 측정만 사용하며, 그 경험은 건드리지 않습니다.
· (+)·측정 시트·DBH/수고/거리/샘플링 플로우·나무 핀·데이터 전부 v2 승인본 그대로. 홈의 (+)는 변신하지 않음.
· 두 세계 분리 유지: 퀵 핀은 크루즈 지도에 나오지 않고, 크루즈 핀은 이 화면에 나오지 않음.
· Cruise 원(하이라이트) 탭 → ① 크루즈 모드. Log 원도 현행 그대로. 불변 — 이 화면과 그 뒤의 퀵 측정 세계 전체(화면·플로우·데이터 모델). 정리 대상 없음.
① 크루즈 모드 — 지도가 곧 크루즈
· Cruise 원 → 크루즈 전용 지도(별도 화면, ‹ 뒤로 = 맵 홈). 같은 지도 픽셀 언어, 크루즈 스코프 크롬.
· 상단 프로젝트 칩 = 제목이자 전환기(탭 → ⑤). 이름은 한 번만 입력, 이후 전부 자동 명명(벤치마크 방식).
· 플롯 링 핀 — 상태색 하나를 전 화면이 공유(규칙 5): 계획 = 빈 점선 / 진행 = 호박 / 마감 = 녹색. 여기엔 크루즈 나무 핀만 표시.
· 크루즈 (+) 상태 변신(규칙 1): 활성 플롯 없음 → "플롯 시작"(AR 링+반경, 샘플링 도구와 동일 컴포넌트) / 활성 → "Add tree · Plot 2" — DBH→수고 직행, 나무 번호 자동. 맵 롱프레스로도 플롯 시작.
· 첫 나무까지: Cruise → 플롯 시작 → 링 저장 → 나무 추가 → Accept×2 = ≤5탭 + 캡처 2회. 정리되는 화면 — TimberCruisingHub(6타일 허브: Cruise 원이 크루즈 모드로 직행), PlotMap(플롯 지도), CruiseFlow 플롯 리스트 픽커. 타일 이주: 필드 로그·참조·설정 → ⑤ 프로젝트 시트 / Tree Measurement 타일 → 맵 홈 (+)이 이미 담당(현행 유지).
② 플롯 피크 — 탤리가 카드 한 장
· 플롯 핀 탭 = 피크 카드(v2 나무 피크와 같은 해부학): 자동 이름(Plot 2) + 상태 칩 + 라이브 BA/밀도/QMD 스트립 — 구 PlotTally의 스탯 스트립이 여기로.
· 주버튼 하나, 54px 풀폭(규칙 5): [나무 추가 · Tree 7] — 다음 번호가 버튼에 이미 적혀 있음. 스캔 체인 직행.
· [플롯 마감] = 핀을 마감색(녹색)으로 스탬프. 검증 이슈는 마감 탭 시 확인 다이얼로그 한 번.
· 활성 플롯 링은 AR 측정 화면에 이미 오버레이됨(기 구현) — 별도 AR 확인 화면 불필요. 정리되는 화면 — PlotTally(스탯+목록+추가), PlotSummary(마감 검증 → 다이얼로그), ARBoundary(링은 측정 화면에 내장).
③ 탤리 루프 — 제로 타이핑
· 나무 번호 자동 증가(007), 수종은 최근값(규칙 2: 레코드당 필수 타이핑 0). GPS·자동사진·시각은 조용히 부착, 실패 시에만 토스트(규칙 3).
· 같은 제스처 반복(규칙 4): Accept → 저장 토스트 → 다음 나무 자동 번호. 진행(n그루)은 항상 보임. DBH → 수고 자동 연결(규칙 5: 기계 단계는 스스로 전진).
· Accept 후 크루즈 지도로 복귀 또는 "다음 나무" 체이닝.
· 구현 개선(내부): 크루즈 캡처도 퀵과 동일한 Accept 경로를 타서 사진+GPS를 자동 상속 — 데이터는 크루즈 모델 그대로, UX 병합 아님. 정리되는 화면 — AddTreeFlow 5단계 스테퍼(수종→DBH→수고→Extras→Review), TreeMeasurementHub(맵 홈 (+)와 중복, 홈이 현행 그대로 담당), ReconCruise(→ 플롯 '카운트 전용' 토글로 흡수).
④ 나무 피크 — 상세는 사후, 절대 게이트 아님
· 크루즈 나무 핀 탭 = v2 피크 해부학 + 사후 상세 칩: 수종/상태/손상은 측정 뒤 언제든 수정(규칙 2: 값을 바꾸는 필드만, 필요한 순간에).
· 방위·중심거리 = 자동 계산(플롯 중심·위치에서) — 기존 Extras 단계의 수기 입력을 대체.
· 원시 품질 메타(σ, inlier 수…)는 화면이 아니라 내보내기 파일로. 정리되는 화면 — TreeDetail(원시 메타 섹션), AddTreeFlow Extras 단계.
⑤ 프로젝트 시트 — 한 번만 입력
· 진입: 크루즈 모드 상단 프로젝트 칩. 프로젝트 = 이름 한 번만 입력(벤치마크 문구 그대로). 이후 자동 명명: Plot 1, 2… / 나무 001, 002…
· 입목 요약(평균 ± CI)과 [전체 내보내기] 한 버튼 — 11개 산출물 목록은 접힘, "개별 파일 선택"으로만 전개.
· 크루즈 설정은 ADVANCED 표기 — 선택 사항임이 화면에서 읽힘. 설정 없이도 이 시트의 모든 것이 동작.
· 허브 타일의 새 집: 필드 로그·참조·설정은 하단 보조 버튼으로 여기서. (맵 홈의 Log 원은 현행 그대로.) 정리되는 화면 — Home(프로젝트 목록), ProjectDashboard(4단계 가이드 + design&&plots 하드 게이트), Export(11개 선택 전용 화면), StandSummary(→ 요약 행에서 리포트로).
⑥ 크루즈 설정 — 3필드, 전부 기본값 (선택)
· 정식 격자 크루즈가 필요한 전문가용 선택 시트: 플롯 크기·유형 / 배치(간격 또는 개수) / 구역 폴리곤(선택). 기존 6필드 전문용어 벽(BAF·scheme·seed)을 기본값 3필드로.
· 생성해도 측정은 잠기지 않음 — 계획 핀은 제안일 뿐. 폴리곤 없는 "단일 임분" 허용(소규모 산주).
· 준비 점검 7게이트 → 자동 점검, 실패 시에만 표시(규칙 3). 정리되는 화면 — CruiseDesign(6필드), StratumDraw(필수 폴리곤), PreFieldChecklist(7게이트).
⑦ 계획 플롯 — 지도가 곧 내비
· 내비 전용 화면 없음: 점선 가이드 + 라이브 거리·방위 칩이 내비의 전부. 5 m 이내 도착 시 진동(현행 로직 유지).
· 계획 핀(빈 점선) 탭 → 피크: [따라가기 / 여기서 중심 기록]. 실제 설치 위치가 계획과 크게 어긋나면 확인 한 번.
· "할 일/방문함" 리스트 픽커 → 핀 색이 곧 목록(계획=빈 점선, 마감=녹색). 정리되는 화면 — Navigation(나침반 전용 화면), CruiseFlow 픽커(잔여분).
⑧ 중심 기록 — 인라인 시트 한 장
· 60초 GPS 평균이 전용 화면 2장이 아니라 지도 위 인라인 시트: 진행 링 + 수렴 중인 ±값. 완료 시 자동 저장(규칙 5), [지금 저장]으로 조기 종료.
· A/B/C/D 티어 용어 → 양호/보통/약함 칩(같은 ok/warn/bad 토큰).
· 오프셋(A–E 5단계) → "GPS 약함? 오프셋 사용" 한 줄 링크 뒤로 — 엣지케이스는 엣지케이스답게. 정리되는 화면 — PlotCenter(60초 전용 화면), OffsetFlow(5단계 스테퍼).
